# Introduccion_Juego

**Nombre del proyecto:** Pixel Adventure (puedes cambiar el nombre)

**Descripción:**  
Juego pixelart 2D en fase beta desarrollado para la clase de Modelación de las Ingenierías y Ciencias. El jugador controla un personaje que debe explorar niveles, evitar obstáculos y recolectar objetos para avanzar. Este proyecto busca aplicar conceptos de programación de juegos, diseño de niveles y animación en 2D.

## Características
- Juego en 2D con estilo pixelart.  
- Movimiento fluido del personaje (caminar atacar).  
- Niveles interactivos con obstáculos y elementos recolectables.  
- Música y efectos de sonido simples.  
- Controles básicos: teclado (flechas o WASD) y tecla de acción (k).  

## Requisitos
- Sistema operativo: Windows, macOS o Linux  
- Unity
